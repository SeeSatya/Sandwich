Keep original ChatGPT diagrams

First add the helper to your browser, then enable it in the ChatGPT conversation you want to copy. The helper preserves each live diagram’s original arrows and layout.

The helper runs locally in your browser and preserves the live SVG. It requires no API key and sends no response text to a service.

1. Add the helper as a bookmark

Show your browser’s bookmarks bar and drag this button onto it. This creates your own Keep ChatGPT diagrams bookmark.

Keep ChatGPT diagrams

Preparing the bookmark…

Clicking the button on this setup page shows these instructions. Run the saved bookmark while you are in ChatGPT.

2. Enable it in the ChatGPT conversation

  1. Open the original response on ChatGPT’s website in this browser.
  2. Click Keep ChatGPT diagrams on your bookmarks bar.
  3. Look for the MarkMind diagram copy helper panel at the bottom left of the ChatGPT page. It should say Diagram copy helper enabled in this tab.

If no panel appears, the helper has not confirmed activation. Use the persistent helper below if your browser blocks the bookmark.

3. Copy the response

Wait for the diagrams to finish rendering, then use ChatGPT’s usual Copy response button. The helper panel should say Preserved … diagrams. Paste the response into MarkMind.

The panel stays visible. If it reports a failure or does not observe copying, use Download helper report to share installation status, call counts, and SVG counts. The report contains no response text, labels, diagram IDs, or page URLs, and downloading it leaves your copied response on the clipboard.

Run the bookmark again after reloading ChatGPT. Use Disable helper in the panel when finished.

Alternative: enable automatically

If you use a userscript manager, install the persistent helper. It activates when a ChatGPT page opens, so you can keep using Copy response across reloads.

Install persistent helper

The helper checks that each copied diagram matches its live SVG. If a diagram is unavailable or does not match, it keeps the original copy and reports that it could not preserve the diagrams.
